# Che Wang — Graphics Field Terminal

Personal graphics portfolio: https://glorykazimierz.github.io/

A bilingual static portfolio with a draggable crystal, interactive lighting, a shader playground, project details and résumé contact links.

## Edit

- `index.html`: page content, links and bilingual labels.
- `app.js`: project records, filters, dialogs and language controls.
- `scene.js`: perspective crystal scene, lighting, floor shadows and reflection.
- `shader.js`: WebGL experiments and Canvas compatibility path.
- `styles.css`, `terminal.css`, `terminal.js`: layout, terminal interface and light controls.
- Résumé links open an email request. The PDF is not included in this publication.

Push static files to the repository's main branch to update GitHub Pages. No dependencies or build step are required. `.nojekyll` preserves the static assets unchanged.

The artwork and interface are original, with an Arknights-inspired visual direction. No official game character art or logos are bundled. The interactive visual experiments are separate from the engineering project results. Project benchmark limitations are explained in the corresponding project dialog.

The previous portfolio remains available in Git history before this redesign.
